# LarkWarning 🐸

> 牛马互助，摸鱼预警。老板来了先别慌，给同事一个撤退信号。

LarkWarning 是一个基于局域网广播的 Windows 桌面小工具，适合熟人或同事之间发送轻量的状态提醒：日常摸鱼、老板突袭、解除警报，一键通知同组伙伴。

它没有主界面、没有托盘图标，启动后安静地躲在后台；收到信号时才用一个醒目的宠物图标提醒你。

## 功能

- 全局热键发送日常、紧急和解除信号
- 局域网 UDP 广播与监听，多台电脑互相提醒
- 普通警告、紧急警告使用不同颜色和宠物图标
- 图标支持左上、右上、左下、右下和屏幕中心
- 图标大小可调，最大 400 像素
- 设置窗口可配置端口、宠物、位置和热键
- 后台运行，不显示主窗口，不抢占工作焦点
- 可选开机自启和声音提示

## 默认暗号

| 用途 | 默认热键 |
| --- | --- |
| 日常摸鱼 | `Ctrl + Alt + L` |
| 老板突袭 | `Ctrl + Alt + K` |
| 解除警报 | `Ctrl + Alt + J` |
| 呼出设置 | `Ctrl + Alt + Shift + S` |

所有热键都可以在设置窗口中修改。不同电脑需要使用相同的广播端口，才能互相收到信号。

## 使用方式

1. 在每台电脑上启动 `LarkWarning.exe`。
2. 确认 Windows 防火墙允许程序进行局域网通信。
3. 按默认热键，或按设置热键打开配置窗口。
4. 同一小组的电脑设置相同端口后，即可互相发送提醒。

配置文件 `config.ini` 会自动生成在程序目录中，也可以通过设置窗口修改。建议在首次使用时先约定好端口和热键，避免和其他程序冲突。

## 构建要求

- Windows 10/11
- .NET 8 SDK
- Visual Studio 2022 或更高版本

```powershell
dotnet build -c Release
```

生成文件位于：`bin/Release/net8.0-windows/`

## 注意事项

- 本项目只适合在获得同事同意的熟人小组内使用。
- 请遵守公司制度和当地法律法规，不要在不知情的设备上运行或利用它干扰他人工作。
- UDP 广播通常只能在同一局域网内工作，跨网段或经过严格隔离的网络可能无法互通。
- 本项目不保证预警一定能及时显示，请不要将它用于安全生产、应急通知或其他关键场景。
